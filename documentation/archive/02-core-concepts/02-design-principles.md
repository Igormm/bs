## Technical Debt Analysis

### Найденные проблемы и решения

1. **Отсутствие копирования lib/ при установке**
   - **Проблема:** В install.sh не копируется директория lib/
   - **Решение:** Добавить `cp -a "${SOURCE_ROOT}/lib" "${TARGET_LIB}/"`
   - **Приоритет:** Критический

2. **Дублирование функций в system модулях**
   - **Проблема:** Функции есть и в lib/system.sh и в отдельных модулях
   - **Решение:** Удалить lib/system.sh или сделать его агрегатором
   - **Приоритет:** Средний

3. **Process substitution с local переменными**
   - **Проблема:** `local` в process substitution может не работать в старых bash
   - **Решение:** Вынести `local` за пределы while
   - **Приоритет:** Средний

4. **Отсутствие set -euo pipefail в модулях**
   - **Проблема:** Некоторые модули не используют строгие проверки
   - **Решение:** Добавить `set -euo pipefail` в начало каждого модуля
   - **Приоритет:** Низкий
